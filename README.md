# 🛍️ Savey Econers

> **Flutter e-commerce mobile application built with Provider and MVVM architecture.**

Economers is a Flutter-based mobile shopping application designed to provide users with a clean and organized shopping experience.

The application follows the **MVVM architecture** and uses **Provider** for state management.

---

## ✨ Features

### 🏠 Home

Explore trending and helpful products through the application's main product browsing experience.

### ❤️ Favorites

Save preferred products for quick and convenient access.

### 🛒 Cart

Review selected products, manage the shopping cart, and keep track of purchases and spending.

### 👤 Profile

View and customize user profile information and preferences.

## 🏗️ Architecture

The application follows the **Model–View–ViewModel (MVVM)** architectural pattern to keep the code organized and maintainable.

```text id="7j0g2d"
View
  ↓
ViewModel
  ↓
Model
```

This structure separates UI presentation from application logic and data models.

## 🚀 Getting Started

### Prerequisites

Make sure you have:

* Flutter SDK
* Dart SDK
* Android Studio or VS Code
* Android/iOS emulator or physical device

### Clone the repository

```bash id="c0f3dw"
git clone https://github.com/Ghazanfar-Flutter-Developer/YOUR_REPOSITORY_NAME.git
```

### Navigate to the project

```bash id="7y6k5p"
cd YOUR_REPOSITORY_NAME
```

### Install dependencies

```bash id="z2u5qu"
flutter pub get
```

### Run the application

```bash id="d9x0qk"
flutter run
```
